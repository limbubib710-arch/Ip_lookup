IP LOOKUP is a Python-based terminal utility designed to retrieve publicly available IP and network information.

Built for Android Termux, Pydroid 3 and Linux environments.

✨ Features

- 🌐 Public IP information lookup
- 📍 Approximate IP geolocation
- 🏢 ISP and organization information
- 🔎 IPv4 and IPv6 information
- 🌍 Country and region information
- 🔗 DNS lookup
- 📡 Network information
- 📱 Public phone-number format validation (if supported)
- 💾 TXT report generation (if supported)
- 🎨 Colorful terminal interface

Features depend on the implementation and availability of external services.

📥 Installation

Termux


$ pkg update -y


$ pkg upgrade -y


$ pkg install python git -y



$ git clone https://github.com/limbubib710-arch/Ip_lookup.git

$ cd Ip_lookup


$ pip install requests phonenumbers


$ python lookup.py


🚀 Run


$ python lookup.py

Pydroid 3

1. Install Pydroid 3.
2. Download or clone this repository.
3. Install the required Python packages.
4. Open "lookup.py".
5. Press Run.
